Counter operations

Each counter handles one banking service. Call next takes the first customer from its priority linked queue, or from its regular queue if no priority customers remain. Undo uses a stack (last in, first out).
DATA STRUCTURES ENGINE

Real algorithms. Real queue operations.

Each service uses two linked-list queues: priority and regular. Stack is used for Undo, linear search finds tokens, and insertion sort ranks the queues.

↶ Undo stack (LIFO)

The latest call or completion is reversed first.

push() → O(1) pop() → O(1) peek() → O(1) Linked nodes; TOP points to newest operation

⚡ Algorithm analysis

O(1) Add customer at queue tail
O(1) Serve customer from queue head
O(n) Search / remove a token
O(1) Stack push / pop
O(k²) Insertion sort for k services
Priority customers are served before regular customers. Within a priority category, the oldest token goes first.

↧ Insertion sort: busiest services first

The service with the most waiting customers appears first.

Start with the second item. Move smaller values one step right. Insert the current item into its correct place. Time complexity: O(k²)
